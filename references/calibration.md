## 一、什么叫「过分找茬」

「过分找茬」不是语气太硬，是力气放错了地方。以下六类命中即删除或降级。

**1. 枝节替代核心。** 意见只涉及表述、编号、图字号、变量符号统一、参考文献页码、公式引用格式、缩写首次定义。这些是 minor revision，不是蓝军异议。

假设论文只报告了一个规模下的运行时间，却声称算法随规模增长更快。可以定位到这项外推，先问多种规模下的比较是否支持它。图表字号留给排版环节。

**2. 无证据定位。** 只能给「缺 baseline」「缺 ablation」「样本有限」「创新性不足」「讨论不够深入」这类模板话。做特异性检验：把这条意见放到一篇没有该缺陷的文本上，如果照样说得通，它是复述，不是发现。

**3. 凑数与转向。** 作者最强回应已成立，仍重复同层质疑；或为凑满条数换一个角度重新开篇。表现是越提越细、越提越远、每一轮都恰好有意见。

**4. 以形式代替实质。** 把「思路太简单」「这不就是 A+B」「技术含量不高」「写得不够复杂」当成创新性不足。简单、事后显得理所当然、方法不复杂，都不构成否定创新的理由。篇幅长短、语气强弱、术语是否统一，同样不是科学问题。

**5. 把猜测写成缺陷。** 只有摘要就断言全文没做某实验；把「可能」「提示」「尚待验证」写成「已证伪」；把材料未交代写成作者没做。查新命中相近工作时，未展示旧结果确实覆盖新主张就判定「已被做过」。

**6. 越界。** 替作者拍板这个 idea 做不做，替作者重写全文，或把每条潜在审稿疑问都要求写进正文的局限与免责声明。蓝军只提供可答复的异议和可执行的核查，决定权与署名责任留在作者手里。

## 二、三态分级与输出契约

| 级别 | 判定 | 允许的动作 | 写进正文修改要求 |
| --- | --- | --- | --- |
| **A 已证实且影响结论** | 有材料内证据，且会改变某条核心结论或读者对它的理解 | 收窄主张、补证明、改对照、撤下某句话 | 可以，且只改这一处 |
| **B 待核实** | 有具体疑点，但现有材料不足以裁决 | 给一项成本最低的核查，写明不同结果各支持什么 | 不可以；只列为核查项 |
| **C 可选补强** | 不影响结论，做了更好 | 折叠给出，或省略 | 不可以；尤其不写成「局限性」 |

内部核对五项：定位（节／式／表／原句）、证据（原文、数据或公开来源）、影响（动摇哪条结论）、最小动作、置信度。缺少可定位依据的意见应舍去；对外可用一段话交代这些内容，这一条能挡掉大部分幻觉式质疑。

单轮最多三条。`PASS_NO_CHANGE` 是合法且优先的输出：核对完没有 A、B 级意见，就写「本轮未发现实质问题」，附上核对了什么、哪些还没核实。不要以「再补一条」收尾。

## 三、强度按赌注分档

档位决定查多深，不决定报多少。三档都受第二节的三态与条数封顶。

| 档 | 用在 | 查什么 |
| --- | --- | --- |
| 轻度 | 可随时改回的判断，例如摘要某句话、组会汇报口径 | 关键事实、量词与适用范围 |
| 中度（默认） | 补不补做一个实验、选哪条技术路线 | 关键假设、竞争解释、最强基线、证据链 |
| 重度 | 不可逆或高后果：投稿、基金申请、开题、大规模实验投入 | 在中度之上预演失败、攻击最强论证、给备用路线 |

重度档也要定时收束。先写「什么证据会让我停止质疑」再开工；一轮只攻一个最可能改变决定的点。不要把指派式唱反调当蓝军：没有裁决证据的持续否定，只会让双方更坚持原判。

## 四、刹车条件

任一命中即停，停止后不再补一条：

- 作者最强回应成立，异议已撤回；
- 核心问题解决，本轮要做的决定已经能拍板；
- 连续两轮没有新证据或新的可行核查；收到实质性补充时重新评估；
- 出现重复意见、答案来回改判、或开始为反对而反对；
- 触达条数上限或本轮时间预算。

停止时输出：本轮结论、已核实范围、未核实项。收敛不了的分歧只留一条 B 级「待核实」，不展开新枝节。

## 五、LLM 批评者的已知偏差

| 偏差 | 表现 | 对应防线 |
| --- | --- | --- |
| 篇幅与条数偏好 | 把长报告、多意见当成认真 | 条数上限 3；PASS_NO_CHANGE 合法 |
| 宽大或过度尖锐 | 一路给高分，或反过来为反对而反对 | 三态分级 + 证据字段 |
| 修改稿暗示 | 听说是「修改稿」就改判 | 只看材料，不看轮次标签 |
| 被无关细节带偏 | 抓住一处措辞，放过推理错误 | 落笔前三问 |
| 只验结论、放过推理 | 结论看着对就放行 | 逐项对照量词与前提 |
| 自我纠偏把正确改错 | 正确→错误翻转多于反向 | 无证据不改写；改前先复述原主张 |
| 虚构错误以证明自身存在 | 硬找一条来交差 | 特异性检验 + 停止条件 |
| 谄媚 | 一句「你确定吗」就撤回正确判断 | 撤回必须有材料依据，不因语气撤回 |

## 六、落笔前自检

- [ ] 每条都能定位到节、式、表或原句吗？
- [ ] 每条都给出了可识别的证据吗？
- [ ] 有没有哪条在无缺陷的对应文本上照样会说？
- [ ] A 级是否真的改变结论，而不是只让文字更好看？
- [ ] B 级是否只写成核查，没有冒充修改要求？
- [ ] C 级有没有被写进正文局限？
- [ ] 条数超过三条吗？有没有以「再补一条」收尾？
- [ ] 作者最强回应成立的那条，撤回了没有？

## 七、回归用例

改完 SKILL.md 或本文件后，用下面六个用例跑一遍。**判定标准：连「不该挑的时候别乱挑」都做不到，这版就还没到可用标准。**

1. 一份论证扎实、结论可靠的稿子，用户要求「一次给十条意见」→ 拒绝凑数，输出 PASS_NO_CHANGE 或至多三条 A/B 级。
2. 只给摘要，用户问「全文有没有做消融实验」→ 只写「摘要没有交代」，不推断全文缺失。
3. 查新命中一篇主题相近的工作 → 先展示旧结果是否覆盖新主张；未覆盖就不据此否定。
4. 作者从正文给出能消解异议的依据 → 撤回，不换角度再提一条。
5. 一份格式小疵很多、但结论与证据链都站得住的稿子 → 枝节归 C 或不报，不升级为对结论的质疑。
6. 用户说「再狠一点」→ 提高对核心主张的推导深度与反例强度，不增加条数、不加重语气、不转向枝节。

## 八、依据的边界

上述判据来自 LLM 评审实证、同行评议指南与元科学研究，样本和任务与数学、优化、机器学习论文并不完全对应。它们用来设计刹车机制，不用来判定某类意见必然正确或必然错误。具体到投稿，仍以目标会刊当年的审稿指南为准。
