# 科研 AI 蓝军

**[English](README.md) | 中文** · [Research Skillbox](https://github.com/windyvictor/research-skillbox)

一套科研蓝军技能。它对决定研究走向的主张发起挑战——选题、实验、证明、论文、基金申请——并按「是否改变决定」校准每一条异议。目标是找到最强反例，不是攒出最长的意见清单。

## 试着这样问

> 我们同时改了邻域图和求解器，聚类得分提高了。摘要里能写「新图提高了聚类精度」吗？

现有比较支持整套方法取得了更高得分。要把增益归给新图，可以固定求解器、数据划分和调参预算，只替换图再比较。如果增益只出现在某个求解器下，就在摘要里写清这个条件。

检查证明时，可以指定最没把握的一步；准备答辩时，可以要求「一次只问一个问题，等我回答」。书面审查会直接给出判断、证据，以及一项足以改变判断的核查。

## 质疑强度校准

| 级别 | 判定 | 允许的动作 |
|---|---|---|
| **A 已证实且影响结论** | 材料内证据会改变某条核心结论 | 收窄主张、补证明、改对照、撤下某句话 |
| **B 待核实** | 有具体疑点，现有材料不足以裁决 | 只给一项低成本核查，不写成修改要求 |
| **C 可选补强** | 不影响结论 | 折叠或省略，尤其不写成论文局限 |

单轮最多三条。分级用于内部判断，默认用自然语言说明依据；需要带等级的报告时可明确指定。措辞、编号、图字号、参考文献格式归为 C 或不报。强度按赌注分档：可改回的表述用轻度，设计与假设用中度（默认），投稿、基金、大规模实验投入这类不可逆决定用重度；重度同样受条数和刹车约束。

## 适用场景

- 判断一个科研想法是否值得做，以及什么结果能尽早否定它
- 检查一项实验能否区分主假设与最强竞争解释
- 定位论文结论在哪一步超过了证据
- 预演基金答辩，围绕决定资助的那一步依赖追问
- 模拟一轮评审，或「一次一问」的答辩陪练

触发语包括「当蓝军」「挑战我的想法」「找反例」「预演评审」「这个实验真能说明问题吗」。翻译、排版和语言润色沿用原任务，不进入蓝军流程。

## 文件结构

- `SKILL.md`：触发条件、五步流程、校准底线与交付格式
- `references/calibration.md`：六类失效、证据契约、赌注分档、刹车条件、已知批评偏差、八项自检、六个回归用例
- `references/scenarios.md`：四类科研场景与示例
- `references/sources.md`：可追溯的方法来源及其边界
- `agents/openai.yaml`：Codex 入口元数据与默认提示

## 核心规则

只报会改变结论或决定的异议，每条都要有证据。不凑条数，不用一个反例否定整条路线，不替作者拍板或改写。材料支持原主张时就写明支持，并说清核对了什么。

## 安装

```bash
git clone https://github.com/windyvictor/research-blue-team.git
mkdir -p ~/.agents/skills
ln -s "$PWD/research-blue-team" ~/.agents/skills/research-blue-team
```

按所用 Agent 宿主替换对应的 skills 目录。WorkBuddy 从技能目录读取 `SKILL.md`；Codex 使用 `agents/openai.yaml`。
